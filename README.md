# Python for Data Science — YouTube

Datasets, Python examples and practice notes for Akshay Pattayil’s Malayalam YouTube series.

## Lessons

- [Pandas with Malayalam movies](pandas/) — Series, DataFrame, indexing, filtering, cleaning, apply, groupby, aggregation, pivot and CSV export.

- [Data visualization with Python](data-visualization/) — variable types, chart selection, and 12 visualizations with a runnable notebook and Titanic dataset.

## Download everything

Click **Code → Download ZIP**, extract it, then open the lesson folder you want (**pandas** or **data-visualization**) in VS Code. Keep the CSV beside the Python file and use that folder as the working directory.

Each lesson folder includes its own instructions and dataset source notes.
